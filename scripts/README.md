# Scripts

Utilidades de mantenimiento del repositorio y del entorno.

Ejemplos previstos:

- Descarga del dataset NSL-KDD y verificación de checksum.
- Limpieza de artefactos de entrenamiento (modelos viejos en `motor/models/`).
- Generadores de documentación del expediente.

Regla: los scripts no contienen secretos; toda credencial se lee de variables de entorno documentadas en el README correspondiente.
